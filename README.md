# Proyecto de Planificación Turística en Paraguay

Este proyecto analiza, visualiza y proyecta datos turísticos en Paraguay con un enfoque en:
- Turismo receptivo
- Turismo cultural
- Turismo de compras

## 📂 Estructura
- `data/`: datasets en formato CSV.
- `src/`: scripts en Python.
- `notebooks/`: análisis exploratorio en Jupyter.
- `outputs/`: resultados gráficos y tablas.

## 🚀 Cómo ejecutar
1. Clona este repositorio o descarga el proyecto.
2. Instala dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecuta el script principal:
   ```bash
   python src/main.py
   ```
4. Abre el notebook para exploración:
   ```bash
   jupyter notebook notebooks/analisis_inicial.ipynb
   ```

## 📊 Librerías
- Pandas, Numpy
- Matplotlib, Seaborn
- Scikit-learn
- Statsmodels, Prophet
- Geopandas, Folium
